## Mengapa PunyaSitus hanya memakai plugin resmi terkurasi?

Berbeda dari CMS tradisional yang mengizinkan unggahan berkas `.zip` sembarangan (sering memicu celah keamanan dan situs lambat), seluruh plugin di PunyaSitus adalah modul pihak pertama yang sudah ditinjau keamanannya, terisolasi per situs, dan mematuhi batas skrip publik maksimal `25 KiB`.

## Plugin resmi gratis yang tersedia

1. **`seo-ai-autopilot`**: aktif bawaan untuk sitemap XML, `robots.txt` ramah AI, metadata otomatis, Schema.org `@graph`, dan IndexNow.
2. **`bio-links`**: membuat halaman tautan bio `/link` di domain Anda sendiri dengan penghitung klik tanpa cookie.
3. **`wp-importer`**: mengimpor artikel blog dan gambar dari situs WordPress lama ke status **Draf** agar dapat ditinjau sebelum terbit.
4. **`lead-notifier` (Telegram)**: menghubungkan notifikasi prospek masuk langsung ke Telegram dengan satu klik tanpa mencari `chat_id` secara manual.

## Memasang dan menonaktifkan plugin dengan aman

1. Buka menu **Plugin** di sidebar kiri dashboard.
2. Pilih tab **Terpasang & Gratis**, **Berbayar / Pro**, atau **Custom Dev**.
3. Klik **Pasang** untuk mengaktifkan, atau klik **Atur** untuk membuka pengaturan plugin di dalam halaman plugin tersebut.
4. Jika Anda menonaktifkan plugin, **data pengaturan plugin tetap tersimpan aman** sehingga dapat langsung digunakan kembali jika suatu saat diaktifkan lagi.
